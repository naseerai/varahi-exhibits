How to connect a gateway

  1. Put its keys in the .env file on the server (see .env.example) and restart the app.
  2. In the gateway's dashboard, add the webhook URL shown above, so tickets are issued even if a customer closes the browser after paying.
  3. Use test/sandbox keys first. Switch to live keys when you're ready to take real money.
